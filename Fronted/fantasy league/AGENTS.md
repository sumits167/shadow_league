# Project Instructions

This project uses:

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui

Rules:

- Prefer shadcn/ui components whenever possible.
- Do not reinvent components already provided by shadcn/ui.
- Use lucide-react for icons.
- Use semantic Tailwind colours (bg-background, bg-card, text-muted-foreground).
- Follow the design system in styles/theme.md.
- Reuse existing components before creating new ones.
- Keep layouts clean and minimal.
- No glassmorphism.
- No heavy shadows.
- No inline CSS.
- Use responsive Tailwind classes.
